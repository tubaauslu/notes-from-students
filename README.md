# 📚 Ankara Üniversitesi Mühendislik Fakültesi Not Arşivi (notes_from_students)

**Topic'ler (Etiketler):** `ankara-universitesi`, `muhendislik`, `ders-notlari`, `acik-kaynak`

Bu depo, Ankara Üniversitesi Mühendislik Fakültesi öğrencileri tarafından paylaşılan ders notları, çalışma soruları ve akademik kaynakları düzenli bir şekilde barındırmak amacıyla oluşturulmuştur.

## 🔍 Notları Nasıl Bulurum?

Aradığınız notlara ulaşmak için depodaki **Bölüm > Sınıf > Ders** hiyerarşisini takip edebilirsiniz:
1. Aşağıdaki listeden kendi bölümünüzün klasörüne tıklayın.
2. İlgili sınıf klasörünü seçin (Örn: `1_Sinif`).
3. Çalışmak istediğiniz dersin klasörüne girerek dokümanlara ulaşın.

**Örnek Dosya Yolu:**
`Bilgisayar_Muhendisligi/1_Sinif/BLM101_Programlama/vize_notlari.pdf`
